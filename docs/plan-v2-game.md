## 1. 목적과 대상

### 1-1. 목적
AI가 "이거 할게요"라고 할 때 **그게 무엇이고, 지금 필요한지, 위험한지**를 스스로 판단하는 사람을 늘린다(원래 기획안의 목표 상태). 이번 판에서는 범위를 "AI로 무언가 만드는 사람"에서 **"AI를 쓰는 모든 사람"**으로 넓히고, 그 판단을 게임처럼 연습하게 한다.

### 1-2. 대상 — 나이 조건을 먼저 확인했다
초등학생까지 대상으로 하려면 AI 서비스 자체의 나이 조건을 알아야 한다. 2026-11-09에 원문을 확인한 결과는 이렇다.

| 서비스 | 최소 나이(공식 약관) |
|---|---|
| Claude (Anthropic 소비자 약관) | 18세 이상, 또는 지역에서 요구하는 최소 나이 중 더 높은 쪽 |
| ChatGPT (OpenAI 이용약관) | 13세 이상(또는 그 나라의 최소 나이), 18세 미만은 부모나 법정대리인의 허락 필요 |

그래서 대상을 세 그룹으로 나눈다.

| 그룹 | 누구 | 이 사이트에서 하는 일 |
|---|---|---|
| A. 만드는 사람 | AI로 웹·앱·봇을 만드는 비개발 어른 (지금의 주 대상) | 블록·서비스 유형·운영 문제까지 전부 |
| B. 쓰는 사람 | AI를 일·공부에 쓰는 어른과 청소년(각 서비스 나이 조건 안에서) | 안전하게 쓰기, AI 답 확인하기, 비밀 지키기 |
| C. 함께 배우는 어린이 | 초등학생. **혼자 AI에 가입해 쓰는 것을 전제로 하지 않음** | 가입 없이 배우는 안전 레슨, 보호자·선생님과 함께 보는 모드 |

**"초등학생도 알아듣게"는 모든 글의 쉬움 기준**으로 삼는다. 그룹 C를 실제 이용자로 받을지는 12장의 결정 사항이다.

### 2-3. 글 분량 (대략값, `node scripts/measure-text.mjs`로 다시 잴 수 있음)

센 것: 맞혀보기 질문·해설, 설명 단락 본문(표 글자 포함), 한 줄 정리. HTML 태그를 지우고 공백을 하나로 줄인 글자 수다. 문장은 마침표·물음표·느낌표나 "요"·"다" 뒤 공백에서 자르는 단순 기준이라, 표 칸이 한 문장으로 붙어 세어질 수 있다. 재는 방식에 따라 숫자가 달라지므로 **같은 스크립트로 전후를 비교**하는 데만 쓴다.

| 묶음 | 레슨당 평균 글자 | 60자 넘는 문장 비율 |
|---|---|---|
| 블록 레슨 9개 | 720자 | 9% (15/171) |
| 챕터 "AI와 일하는 법" 4개 | 1,118자 | 26% (25/95) |
| 챕터 "만든 다음에 터지는 것들" 8개 | 1,572자 | 24% (62/258) |

새로 만든 레슨일수록 깊어졌지만, 그만큼 **길고 문장이 길어졌다**. 초등 고학년 기준으로는 줄여야 한다.

### 2-4. 정리: 고칠 점 6가지
1. 성취가 숫자뿐이다. 레벨·배지가 없어 "내가 늘고 있다"는 느낌이 약하다.
2. 진행 방향이 안 보인다. 처음 온 사람이 무엇부터 할지 모른다.
3. 배운 것을 들고 나갈 결과물이 없다. "AI에게 이렇게 물어보세요" 표가 레슨 5곳에 흩어져 있다.
4. 틀린 문제를 다시 볼 곳이 없다.
5. 챕터 2의 글이 길다.
6. 진도가 그 브라우저에만 남는다(1단계 설계대로).

## 3. 게임 설계 원칙

| 원칙 | 구체적으로 |
|---|---|
| 배움에만 점수를 준다 | 경험치는 맞혀보기·실험실 목표 달성·미션처럼 **이해를 보여 주는 행동**에만 준다. 클릭 수나 머문 시간에는 주지 않는다 |
| 불안 대신 성취 | 연속 학습이 끊겨도 벌칙이 없다. 남과 순위를 비교하지 않는다(기본 꺼짐). 제한 시간을 두지 않는다. 어린이도 보는 사이트라서다 |
| 틀려도 손해 없다 | 틀리면 해설과 함께 복습함에 넣고, 점수를 깎지 않는다. 지금의 "처음 답만 점수" 규칙은 그대로 둔다 |
| 손에 남는다 | 챕터마다 들고 나갈 결과물이 하나 이상 생긴다 |
| 정확성은 그대로 | 게임 문구·배지 설명도 출처 규칙을 따른다. 예시 숫자는 화면에 '예시'로 표시한다 |
| 개인정보 0 | 1단계는 이름 하나도 서버로 보내지 않는다. 수료증 이름은 그 화면에서만 쓴다 |

## 4. 게임 시스템

### 4-1. 학습 지도 (홈 화면을 바꾼다)
메뉴 6개를 **지도 한 장**으로 바꾼다. 지금 메뉴 하나(블록, 서비스 유형, 챕터 등)가 지역 하나가 되고, 그 안의 레슨·유형 하나가 칸 하나다.

| 지역 | 들어가는 것 | 칸 수 |
|---|---|---|
| 1. 블록 마을 | 블록 9개 | 9 |
| 2. 조립 공방 | 만들고 싶은 것 7가지 | 7 |
| 3. AI 대화 광장 | AI와 일하는 법 4 + AI 말 번역기 | 4 + 사전 |
| 4. 운영 요새 | 만든 다음에 터지는 것들 8 | 8 |
| 쉼터(지도 한쪽) | 공통 규칙 3가지와 출처 | 칸 없이 언제든 열람 |
| (새 지역) | 7장의 로드맵 | — |

- 칸 상태: 안 감 · 봤음 · 다 맞힘(별) 세 가지를 색과 모양으로 표시한다(색만으로 구분하지 않는다).
- 추천 순서를 길로 그려 주되, **잠그지는 않는다**. 이미 아는 사람이 지루하지 않게 하기 위해서다(잠글지는 12장의 결정 사항).
- "다음에 할 것" 단추 하나로 추천 칸으로 바로 간다.

### 4-2. 경험치와 레벨

| 행동 | 경험치(초안) |
|---|---|
| 맞혀보기·미션을 처음 답에 맞힘 | 10 |
| 틀린 뒤 해설을 끝까지 펼침 | 3 |
| 실험실·화면 부품의 목표 달성(4-4) | 10 |
| 챕터 보스 통과(4-5) | 별 1개당 20 |
| 복습함에서 다시 맞힘 | 5 (점수판의 정답 수는 바뀌지 않음) |

| 레벨 | 이름(초안) | 뜻 |
|---|---|---|
| 1 | AI 새싹 | 이제 막 시작 |
| 2 | AI 탐험가 | 블록이 무엇인지 앎 |
| 3 | AI 조수 | AI의 말을 번역할 수 있음 |
| 4 | AI 감독 | 승인할지 말지 스스로 판단 |
| 5 | AI 길잡이 | 다른 사람에게 알려 줄 수 있음 |

레벨 기준 경험치는 M1에서 **실제 총 경험치를 계산한 뒤** 정한다(지금 문제 44개, 실험실 9개, 화면 부품 8개 기준).

### 4-3. 배지
지금 브라우저에 남는 기록은 네 가지다: 문제별 첫 답(`cs-answers`), 끝낸 서비스 유형(`cs-done`), 맞혀보기에 답한 블록(`cs-seen`), 맞혀보기에 답한 챕터 레슨(`cs-cseen`). `cs-seen`·`cs-cseen`은 레슨을 열기만 해서는 찍히지 않고 **맞혀보기 답을 눌러야** 찍힌다(`lib/store.ts`의 `guess`·`cguess`). 번역기를 본 기록과 화면 부품을 조작한 기록은 없어서 M1에서 새로 남긴다.

| 배지 | 조건 | 판정에 필요한 기록 |
|---|---|---|
| 블록 수집가 | 블록 9개의 맞혀보기에 모두 답함 | 있음(`cs-seen`) |
| 첫 승인 판단 | 서비스 유형 미션 하나를 맞힘 | 있음(`cs-answers`) |
| 조립 장인 | 서비스 유형 7개를 모두 끝냄 | 있음(`cs-done`) |
| 운영 요새 정복 | 챕터 2의 8개 레슨의 맞혀보기에 모두 답함 | 있음(`cs-cseen`) |
| 번역가 | AI 말 번역기를 끝까지 봄 | 새로 추가 |
| 위험 탐지기 | 위험 표시가 붙은 번역기 말을 모두 봄 | 새로 추가 |
| 메모리 탐정 | 메모리 시뮬레이션에서 '모자라요'를 만들어 봄 | 새로 추가 |
| 0과 모름 | '못 읽은 값' 부품에서 세 상태를 모두 눌러 봄 | 새로 추가 |
| 한도 측정가 | 속도 제한 부품에서 거절이 0이 되는 최대값을 찾음 | 새로 추가 |
| 되돌리기 장인 | 삭제 미리보기에서 ROLLBACK으로 5건을 지켜 냄 | 새로 추가 |
| 한 번만 | 재시도 부품에서 멱등성 키로 게시물 1개를 지킴 | 새로 추가 |
| 다시 일어서기 | 복습함에서 틀렸던 문제 5개를 다시 맞힘 | 새로 추가 |

### 4-4. 실험실 목표 퀘스트
지금 화면 부품은 "만져 보기"에서 끝난다. 부품마다 **목표 한 줄**을 주고, 달성하면 체크와 경험치를 준다.

| 부품 | 목표 예 |
|---|---|
| 메모리 시뮬레이션 | 테스트 작업을 켜고도 여유가 남는 봇 메모리 최대값 찾기 |
| 따로 묻기 vs 묶어 묻기 | 따로 물어도 3초를 넘지 않는 최대 종목 수 찾기 |
| 디스크 계산기 | 남은 날을 90일 이상으로 만들기 |
| 못 읽은 값 | ①과 ②가 다르게 반응하는 상태 찾기 |
| 1분 한도 | 거절이 0인 최대 요청 수 찾기 |
| 반복 호출 요금 | 한 달 요금을 1만 원 아래로 만드는 간격 찾기 |
| 삭제 미리보기 | 표를 비워 버리는 조합 찾기, 그다음 되돌리는 조합 찾기 |
| 재시도 | 세 번 보내도 게시물이 1개인 상태 만들기 |

정답은 부품의 계산식으로 자동 판정한다. 새 사실 문장이 필요 없어 출처 규칙에 걸리지 않는다.

### 4-5. 챕터 보스: "승인할까요?"
챕터 끝에 **AI가 보낸 것 같은 메시지 5개**를 연속으로 보여 주고, 승인 · 먼저 확인 · 거절 중 고르게 한다. 맞힌 수에 따라 별 1~3개를 준다. 문제는 **이미 출처가 붙은 레슨 내용에서만** 만든다. 예: "디스크가 가득 차서 로그를 전부 지울게요" → 먼저 확인(무엇을 지우는지, 백업이 있는지).

### 4-6. 복습함
처음 답에 틀린 문제를 모아 둔다. 다시 맞히면 복습함에서 빠지고 "다시 일어서기" 배지에 가까워진다. 점수판의 정답 수는 그대로 둔다(첫 답 규칙 유지).

### 4-7. 배운 날 달력 (선택)
배운 날에 도장을 찍는다. 끊겨도 벌칙이 없고, 연속 기록을 강조하지 않는다.

## 5. 손에 남는 결과물

| 결과물 | 언제 생기나 | 모양 | 어디에 쓰나 |
|---|---|---|---|
| ① 나의 AI 안전 수칙 카드 | 레슨을 끝낼 때마다 그 레슨의 한 줄 정리가 카드에 한 줄씩 붙음 | 이미지(PNG) 저장·인쇄 | 책상·모니터 옆에 붙여 두기 |
| ② AI에게 물어볼 질문 꾸러미 | "AI에게 이렇게 물어보세요" 표가 있는 레슨을 끝낼 때 | 복사 단추, 텍스트 파일 저장 | 실제 AI 대화창에 그대로 붙여 쓰기 |
| ③ 내 서비스 설계도 | 만들고 싶은 것을 골라 조립도를 끝낼 때 | 필요한 블록과 주의할 점 한 장 | AI에게 일을 맡기기 전에 함께 보기 |
| ④ 출발 전 점검표 | 운영 요새 지역을 끝낼 때 | 체크리스트(인쇄용) | 배포·결제 전 마지막 확인 |
| ⑤ 지역 수료증 | 지역 하나를 끝낼 때 | 이름(화면에서만 입력)·날짜·배지가 들어간 이미지 | 성취 기록·공유 |
| ⑥ 도감 | 계속 | 모은 블록·번역기 말은 컬러, 아직은 회색 | 모으는 재미 |

- 모두 **브라우저 안에서** 만든다(그림 그리기 기능으로 PNG 생성). 서버로 아무것도 보내지 않는다.
- 결과물에 들어가는 글은 이미 승인된 레슨 문장(한 줄 정리, 질문 표)을 그대로 쓴다.

## 6. 쉬운 말 기준

### 6-1. 기준
| 항목 | 기준 |
|---|---|
| 독자 | 초등 5~6학년이 혼자 읽고 이해 |
| 문장 | 한 문장 60자 이하가 원칙 (2-3의 측정 기준과 같음) |
| 단락 | 3~4문장 |
| 레슨 본문 | 기본으로 보이는 부분 약 900자 이하. 나머지는 '더 깊이' 접기로 |
| 용어 | 처음 나올 때 괄호로 풀이. 영어 용어는 우리말 뜻을 먼저 |
| 숫자 비교 | 글보다 화면 부품·그림으로 |

### 6-2. 3단 깊이
모든 레슨을 **한 줄 → 쉬운 설명 → 더 깊이(접기)**로 나눈다. 쉬운 사람은 위만 읽고, 깊이 알고 싶은 사람은 펼친다. "더 깊게, 대신 쉽게"를 둘 다 지키는 방법이다. 출처와 원문 인용은 '더 깊이' 안에 그대로 남긴다.

### 6-3. 장치로 지킨다
- 빌드 검사에 **긴 문장 경고**와 **풀이 없는 영어 용어 경고**를 추가한다. 처음에는 경고로 시작하고, 레슨을 다 고친 뒤 실패로 바꾼다.
- 기존 레슨을 다시 쓰는 것은 문장 변경이므로, 지금 규칙대로 **레슨마다 미리보기와 함께 승인**받는다.

## 7. 콘텐츠 로드맵 (새 지역 후보)

모든 새 내용은 지금과 같이 **공식 문서 원문 대조 → 독립 검토 → 승인** 순서로 만든다. 아래 '근거'는 확인한 것과 앞으로 조사할 것을 구분했다.

| 순서 | 새 지역 | 무엇을 배우나 | 근거 |
|---|---|---|---|
| 1 | 비밀과 개인정보 지키기 | AI 대화창에 넣으면 안 되는 것(키, 비밀번호, 남의 개인정보), 대화 기록·학습 설정 확인하기, 어린이 개인정보 | 개인정보 보호법 제22조의2 (확인함). 각 AI 서비스의 데이터 설정 문서는 조사 필요 |
| 2 | AI 답 확인하기 | AI가 틀릴 수 있다는 것, 출처 요청하기, 숫자·날짜 다시 확인하기 | 각 AI 서비스의 공식 도움말 조사 필요 |
| 3 | AI에게 일 잘 시키기 | 목적·맥락·예시를 주는 법, 결과를 검증하게 시키는 법 | 각 AI 회사의 공식 프롬프트 안내 조사 필요 |
| 4 | 보호자·선생님 안내 | 서비스별 나이 조건, 아이와 함께 쓰는 법 | Claude·ChatGPT 나이 조건 확인함. 다른 서비스는 조사 필요 |
| 5 | 업계 소식 코너 | 빨리 바뀌는 소식. 확인일을 크게 표시 | 원래 기획안에서 1단계 제외로 정했던 것 |

## 8. 기술 설계 (지금 구조 위에서)

| 항목 | 설계 |
|---|---|
| 구조 | 1단계 그대로: 정적 사이트, 서버·DB 없음. 경험치·배지·복습함·결과물 모두 브라우저 저장소로 가능 |
| 저장 | 지금 저장 키 4개(`cs-answers`, `cs-done`, `cs-seen`, `cs-cseen`)는 그대로 두고, 새 기록은 키 하나(`cs-game`)에 버전 번호와 함께 저장. 지금 `cs-answers`처럼 망가진 값을 막는 검증을 둠 |
| 규칙도 데이터로 | 레벨·배지·퀘스트·보스 문제를 `content/game/*.json`으로 두고, 검사 스크립트가 "없는 레슨 id를 가리키는 배지" 같은 실수를 빌드에서 막음 |
| 결과물 이미지 | 브라우저의 그림 그리기 기능(canvas)으로 PNG를 만들어 내려받기. 외부 전송 없음 |
| 검사 | 수강생 전 과정 검사에 경험치 계산·배지 획득·결과물 생성 확인을 추가 |
| 성능 예산 | 지금 수준 유지: JS 메모리 약 4MB, 첫 화면 작업 2.4초(휴대폰 조건)를 크게 넘지 않게 |
| 진도 옮기기 | 2단계(로그인) 전에 **진도 파일 내보내기·불러오기**를 먼저 둔다. 개인정보 없이 기기를 바꿀 수 있다 |
| 2단계 로그인 | 원래 기획안대로 "기기 간 진도 요청이 실제로 나올 때". 만 14세 미만의 개인정보를 동의로 처리하려면 법정대리인 동의를 받고 확인해야 한다(개인정보 보호법 제22조의2 ①). 그래서 로그인을 열 때 나이 정책을 먼저 정한다 |
| 사용 통계 | 지금은 없다(서버 없음). 통계 도구를 넣을지는 개인정보·비용 문제라 12장의 결정 사항 |

## 9. 개발 순서

| 단계 | 내용 | 문장 변경 | 끝났다고 보는 기준 |
|---|---|---|---|
| M1 게임 뼈대 | 경험치·레벨·배지 판정(새 기록 `cs-game` 포함), 홈을 학습 지도로, "다음에 할 것" 단추, 진도 파일 내보내기·불러오기 | 기존 레슨 문장 변경 없음. 새 게임 문구는 승인 | 지도에서 모든 칸 상태가 맞게 보이고, 배지 12개 판정이 검사로 확인됨 |
| M2 결과물과 복습 | 안전 수칙 카드, 질문 꾸러미, 복습함 | 없음(승인된 문장 재사용) | PNG·텍스트 저장이 휴대폰·PC에서 됨 |
| M3 퀘스트와 보스 | 화면 부품 목표 8개, 챕터 보스 | 보스 문제는 새 문장 → 승인 | 목표 자동 판정, 보스 별 계산이 검사로 확인됨 |
| M4 쉬운 말 다시 쓰기 | 긴 문장·용어 검사 도입, 레슨을 3단 깊이로 | 있음 → 레슨마다 승인 | 경고 0건이 되면 검사를 실패로 전환 |
| M5 새 지역 1 | 비밀과 개인정보 지키기 | 새 레슨 → 승인 | 지금과 같은 출처·검토 기준 통과 |
| M6 수료증·도감·설계도·점검표 | 결과물 ③④⑤⑥ | 점검표는 승인된 챕터 2 문장으로 만들되, 새 문장이 생기면 승인 | 저장·인쇄 확인 |

각 단계는 지금처럼 브랜치 → 검사 → 독립 검토 → PR로 진행한다. 화면에 나가는 새 문장은 미리보기와 함께 승인받는다.

## 10. 잘 되고 있는지 보는 법

서버가 없어 사용 기록을 모으지 않는다. 그래서 처음에는 원래 기획안의 1단계 조건처럼 **본인과 지인 몇 명이 끝까지 풀어 보고** 아래를 본다.

| 보는 것 | 어떻게 |
|---|---|
| 끝까지 간 사람 | 지역 하나를 끝낸 사람 수 |
| 막힌 곳 | 어디서 멈췄는지, 무슨 말이 어려웠는지 직접 묻기 |
| 다시 온 날 | 배운 날 달력에 찍힌 날 수(본인이 보여 줄 때만) |
| 결과물 | 수칙 카드·질문 꾸러미를 실제로 저장하고 썼는지 |

## 11. 위험과 대응

|---|---|
