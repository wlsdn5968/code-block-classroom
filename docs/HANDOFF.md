## 알아 둘 것
- 임시 폴더(scratchpad)는 앱을 다시 켜면 비워진다. 계속 쓸 도구는 `scripts/`(레슨 도우미 `lesson-tools.mjs`). 출처 원문 보관본이 없어 인용 대조는 매번 원문을 내려받아서 한다(`https://code.claude.com/docs/en/<page>.md`).
- **표현을 고칠 때는 PR을 만들기 전에** 옛 표현을 화면 파일 전체(`content/`·`components/`·`lib/`·`app/`)에서 찾는다. 보스·사건·수칙·문장 카드(`content/game/`, `phrases.json`, `lib/kit.ts`)를 두 번 놓쳤다(28-5, 29-2). `check-plain`은 레슨만 보고 보스·문장 카드는 보지 않는다.
- 콘텐츠에 새 HTML 태그·속성을 쓰면 `scripts/check-html.mjs`의 허용 목록에 더해야 빌드가 통과한다(허용: `b code br p div table tr th td`, `class data-new`). 출처 주소에는 따옴표·꺾쇠를 쓸 수 없다.
- 새 출처를 더하면 `scripts/verify-port.mjs`의 "원본에 없는 출처" 목록에도 넣어야 빌드가 통과한다. 빌드가 실패해도 `test:walk`는 예전 `out/`을 검사해 통과할 수 있으니 빌드 성공과 함께 본다(28-7).
- 쉬운 말 검사: 영어 낱말은 바로 뒤의 괄호 풀이만 인정하고 괄호 안의 영어는 보지 않는다. 코드 글꼴(`<code>`)과 표는 문장 길이·영어 검사에서 빠지지만 900자에는 들어간다. 더 깊이 보기 단락은 900자·60자 검사에서 빠진다.
- 화면의 확인일 문구("가장 최근 …에 확인")는 `content/sources.json`의 가장 최근 `checkedAt`과 같아야 빌드 전 검사를 통과한다.
- 올리지 않은 패키지: TypeScript 7, ESLint 10. 개발 도구 보안 경고 7건(minimatch). 보고서 25-4. 이미 합쳐진 브랜치는 그대로 둔다(2026-11-17 승인).
